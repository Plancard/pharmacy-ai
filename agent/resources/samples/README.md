# Agent 샘플 (더미)

**전부 가짜입니다.** 실제 환자·의료기관·의료인 정보가 없고, 위험 신호 문장과 근거는 형식을 보이려는 예시입니다
(`(가짜 데이터)`로 시작하는 문장은 그대로 화면에 나가면 안 됩니다). 실제 위험 신호는 13단계(DUR)에서 API 응답으로 채웁니다.

폴더 이름은 명세서 부록 A의 번호입니다. 모양은 `agent/schema.py`가 정하고, `tests/agent/test_schema.py`가 매번 검사합니다.

| 폴더 | 형식 | 방향 | 파일 |
|---|---|---|---|
| `a1_ocr/` | A.1 OCR 결과 | CV → Agent | `s01_combo_a` · `s02_combo_b` · `s03_no_risk` · `s04_flagged` · `s05_no_code` |
| `a5_order/` | A.5 조제지시서 (+ `risk_check`) | Agent → 웹 | A.1과 같은 이름. **A.1을 읽은 최종 정답** (약품 매칭·위험 신호 대조까지 끝난 모습) |
| `a4_plan/` | A.4 조제 계획 | Agent → CV | `s01_combo_a` (a5의 같은 이름에서 나온 계획) |
| `a3_inspection/` | A.3 검수 결과 | CV → Agent·웹 | `i01_ok` (12칸 모두 ok) · `i02_mismatch` (불일치 1칸 + 확인 필요 1칸) |
| `a6_consult/` | A.6 상담 결과 | Agent → 웹 | `c01_combo_a_rx_only` · `c02_no_risk_with_current_meds` |
| `cv_a1/` | A.1 (CV가 보낸 실제 형식) | CV → Agent | `rx_001` ~ `rx_005`. `cv/fixtures/a1`을 그대로 복사해 동결한 것 |
| `cv_expected/` | 위 5장의 정답 | | OCR이 읽은 글자 기준 정답. 환자 이름·주민번호는 없다 |
| `rx8_a1/` | A.1 (시연용) | CV → Agent | `rx8_01` ~ `rx8_08`. **실제 대상 8종으로 만든 가상 처방전.** `scripts/agent/make_prescriptions.py`가 만든다 |
| `rx8_expected/` | 위 8장의 정답 | | 약품 줄 · 위험 신호 단계 · 조제 계획을 만들 수 있는지 |
| `rx8_img/` | 처방전 이미지 (PNG) + CV 정답 | | 위 8장을 CV 가상 처방전과 같은 양식(별지 제9호 서식)으로 그린 것. `ground_truth.json` · `gt.json`은 CV `cv/ocr_test.py --gt`에 그대로 넣는다 |

`cv_a1/`은 CV가 샘플을 바꿔도 우리 시험이 같이 흔들리지 않도록 복사해 둔 것입니다. 원본과 달라지면
`test_schema_contract.py`가 알려 주니, 그때 복사본과 `cv_expected/`를 함께 갱신합니다.

## 가상 처방전 5장

| 샘플 | 약 | 보여 주는 것 |
|---|---|---|
| `s01_combo_a` | 타이레놀정500mg · 게보린정 | 시연 조합 A: 아세트아미노펜 중복 → `warning` |
| `s02_combo_b` | 트리스펜연질캡슐 · 아르펜정 | 시연 조합 B: 이부프로펜 중복 → `warning` |
| `s03_no_risk` | 프론크논캡슐 · 뮤코다인캡슐200mg | 위험 신호 없음 → `none`. 1회 2알 |
| `s04_flagged` | 프론크논(OCR 오독) · 트립라인 · 아이월드요비신정 · 알모탄(대상 아님) | `danger`+`caution`, 약사 확인 표시 2줄, 취침 전(`bedtime`) 1회 |
| `s05_no_code` | 타이레놀정500mg · 뮤코다인캡슐200mg | **약품 코드가 인쇄되지 않은 처방전.** 규칙 읽기는 약품 줄을 못 찾아 실패하고 LLM이 읽어야 한다 (3단계) |

대상 8종(CV의 `cv/classes.yaml`, 명세서 2.6절)이 s01~s05에 모두 한 번 이상 나옵니다. 약 이름은 `classes.yaml`과 같습니다. 알모탄정은 대상 8종이 아니라 `item_code`가 `null`입니다.

## 규칙

- 처방전에 인쇄된 코드 `9000000xx`는 CV가 올린 샘플(`cv/fixtures/a1`)이 쓰는 가상 코드를 이어 썼습니다
  (타이레놀 011 · 게보린 021 · 알모탄 031 · 트리스펜 041 · 프론크논 051). 나머지는 이 샘플에서 새로 정했습니다
  (아르펜 061 · 아이월드요비신정 071 · 트립라인 081 · 뮤코다인 091). **CV의 가상 처방전이 같은 코드를 쓰는지는 CV에 확인이 필요합니다.**
- 줄 배치(표 머리글·행 간격·정렬 순서)는 `cv/fixtures/a1`을 따랐고, 환자 이름·주민번호 줄은 일부러 넣지 않았습니다.
- 복용 시점: 1회 → `morning`(용법에 "취침 전"이면 `bedtime`) · 2회 → `morning`+`evening` · 3회 → `morning`+`noon`+`evening`.
- `source_line_ids`: 그 약 한 줄을 읽은 A.1 줄 전부 — 약품명 · 1회량 · 횟수 · 일수 · 용법.
- `name`: 약품 사전에 있는 이름. 약을 정하지 못한 줄은 읽은 이름 그대로.
- 위험 신호 `type` 값(`ingredient_dup` · `contraindication` · `age_caution`)은 임시입니다. 13단계에서 DUR 응답에 맞춰 확정합니다.

## 시연용 처방전 8장 (rx8_*)

양식은 CV 팀 가상 처방전(rx_001~005)과 같습니다: 칸 위치, 가상 환자 · 의료기관 · 의료인, 약품 줄 "(1)코드 이름/함량",
용법 "PO 식후 30분". 실제 대상 8종만 쓰고, 트레이 규격(명세서 2.7절: 3일 이하, 칸당 2알 이하)을 지킵니다.
약품 코드 칸에는 품목기준코드를 인쇄해 약품 매칭이 코드 단계에서 자동 확정됩니다. 용법에 시점이 없으므로
Agent가 하루 횟수로 시점을 배정하고 경고를 답니다 (취침 전 약만 "PO 취침 전"). 처방 내용을 바꿀 때는 `scripts/agent/make_prescriptions.py`의 표를 고치고 다시 돌립니다.

| 샘플 | 약 | 보여 주는 것 |
|---|---|---|
| `rx8_01` | 타이레놀정500mg · 게보린정 (3회 3일) | 시연 조합 A: 아세트아미노펜 중복 → `warning` |
| `rx8_02` | 트리스펜연질캡슐 · 아르펜정 (2회 3일) | 시연 조합 B: 이부프로펜 중복 → `warning` |
| `rx8_03` | 프론크논캡슐 · 뮤코다인캡슐200mg (3회 3일) | 위험 신호 없음 |
| `rx8_04` | 타이레놀정500mg · 트립라인정 (3회 3일) | 외형이 비슷한 두 약 (CV 혼동 평가) |
| `rx8_05` | 뮤코다인캡슐200mg 2알 (2회) · 트립라인정 (취침 전) | 칸당 2알을 꽉 채움, 취침 전 칸 |
